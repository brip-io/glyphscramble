# Per-response delivery

Rotate the encoding for each protected response and serve its short-lived matching font.

Source: https://glyphscramble.brip.io/docs/delivery/per-response/

Use per-response delivery when your Node server can keep a process-level GlyphScramble engine alive between the protected document and its later font request.

## Server boundary

```ts
import { createGlyphEngine } from "@brip/glyphscramble";
import config from "./glyphscramble.config.js";

const engine = await createGlyphEngine(config);

export async function protectedPayload(text: string) {
  const response = engine.beginResponse();
  return response.scrambleAsync(text, { font: "body", lang: "en" });
}

export function fontRoute(request: Request) {
  return engine.fontResponse(request);
}
```

Create one engine per process, not one per request. `createGlyphEngine()` starts and primes the bounded variant provider before it resolves. Use one response context for all protected blocks in a document.

## Deployment requirements

The beta runtime stores generated bytes and compact encode mappings in memory. A font request must reach the engine instance that issued its token. Supported adapters therefore target a single Node process. Load-balanced, clustered, edge, function-per-route, and restart-prone deployments need request affinity or an external `FontVariantProvider`; do not claim those topologies as supported yet.

Drain an instance after removing it from application traffic. `engine.drain()` keeps issued fonts available until expiry or a bounded shutdown deadline.

## Cache behavior

The protected document is `private, no-store`. Apply that header only when `ResponseContext.used` is true. An unused context must not disable an otherwise cacheable page.

The matching font is `private, max-age=<remaining>, immutable`. Its lifetime cannot exceed the token lifetime. Do not place either artifact in a shared public cache.

## Capacity and failure

The response pool and byte cache are bounded. Size them from generated WOFF2 size, mapping storage, peak protected-response rate, and `tokenTtlSeconds`. Overload, acquisition timeout, missing secret, expired token, wrong instance, font failure, or CSP refusal must produce a generic unavailable state without the source text.

See [Caching and CDNs](/docs/operations/caching-cdn/) and [Troubleshooting](/docs/operations/troubleshooting/) before production rollout.
