# Brand icons

These nine SVG marks are sourced from Simple Icons 16.28.0 through
`@icons-pack/react-simple-icons` 13.15.1 and are used under CC0-1.0.
Simple Icons is available at https://github.com/simple-icons/simple-icons.

The marks identify their respective projects and package managers. Their
trademarks remain the property of their owners. CSS uses these files as masks
so the installation selector can follow the site's light and dark themes.
