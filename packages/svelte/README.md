# @brip/glyphscramble-svelte

Payload-only Svelte 5 component and action for GlyphScramble by BRIP.

```bash
npm install @brip/glyphscramble @brip/glyphscramble-svelte
```

Pass only a server-produced `GlyphPayload`. Read the [Svelte and SvelteKit
guide](https://github.com/brip-io/glyphscramble/blob/main/docs/FRAMEWORKS.md#svelte-5-and-sveltekit-2)
and protect only optional, high-value content.

GlyphScramble raises the cost of bulk DOM scraping; it is not DRM. Apache-2.0.
