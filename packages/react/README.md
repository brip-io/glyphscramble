# @brip/glyphscramble-react

Payload-only React component and server helper for GlyphScramble by BRIP.

```bash
npm install @brip/glyphscramble @brip/glyphscramble-react
```

Plaintext belongs in the server helper; Client Components accept only a
`GlyphPayload`. Read the [React integration guide](https://github.com/brip-io/glyphscramble/blob/main/docs/FRAMEWORKS.md#react-and-next-16)
and [responsible-use boundary](https://github.com/brip-io/glyphscramble#good-fit).

GlyphScramble raises the cost of bulk DOM scraping; it is not DRM. Apache-2.0.
