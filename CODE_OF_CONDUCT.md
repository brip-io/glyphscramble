# Contributor Covenant Code of Conduct

We pledge to make participation in this project a harassment-free experience for everyone. Be respectful, accept constructive feedback, focus on what is best for the community, and show empathy toward other contributors.

Unacceptable behavior includes harassment, discriminatory language, sexualized attention, threats, doxxing, and sustained disruption. Maintainers may remove or reject contributions and participation that violate these expectations. Report conduct issues privately to the BRIP maintainers. Enforcement will be fair, confidential, and proportionate.

This policy is based on Contributor Covenant 2.1.
