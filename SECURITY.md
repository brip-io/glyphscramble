# Security policy

Please do not open a public issue for a vulnerability. Use GitHub private vulnerability reporting on `brip-io/glyphscramble`.

The project is pre-1.0. Security support covers the newest published beta only. Reports that a valid recipient can recover text through a headless browser, OCR, or font analysis describe documented boundaries, not vulnerabilities. Token forgery, cross-request confusion, unexpected plaintext leakage, parser memory-safety issues, and bypasses of fail-closed behavior are in scope.
